# Current map

The current `house.js` is an authored 88×68-stud one-floor social house and park, with a 24-stud ceiling, 12 meeting-table chairs, 8 TV chairs, player-sized playground, and park seating. Static geometry is batched. Server geometry is mirrored from `map-server.json`.

The previously extracted user-supplied Happy Home remains preserved in `house-extracted.json`; it is not the active map. No source-place scripts are executed.

The TV uses a random allowlisted Picsum photo selected once by the server and stored in D1, with image bytes fetched server-side. It is a web photograph, not generated art.
